Corrected edition · 12 November 2026. These are study-specific mechanisms and examples, not platform-wide restrictions or validated experimental results.

The paper puts a small, quantized language model beside a control board, not inside its fast loop. The model reads the board's signals as tokens and proposes parameters; deterministic code decides what reaches the pins.

§2.1 – 2.2 · Generative control frameworks

Two ways to move control inside the model

CELI · Controller-Embedded Language Model Interactions

Wagner et al., 2024

Conventional integrations wrap the model in a hard-coded external loop and query it as a passive text generator. CELI moves the control logic into the prompt architecture, so the model drives multi-stage execution itself.

Autonomous state management. The model tracks workflow transitions without external procedural scaffolding.
Arbitrary function calling. Semantic states map to hardware tool actions, register changes or API calls with validated, structured arguments.
State-aware efficiency. Immutable action paths are cached and only delta state tokens are passed, skipping redundant decoding.

ELF · Embedded Language Flows

Hu et al., 2026

Projecting onto discrete tokens at every step adds quantization noise and latency at a continuous physical interface. ELF keeps reasoning in the embedding space via flow matching, so live sensor feedback can enter the generative trajectory smoothly.

§2.3 – 2.4 · Scaling to edge hardware

Fitting a transformer onto edge silicon

Four optimization pillars, as surveyed by Lamaakal et al. (2025), take a transformer (Vaswani et al., 2017) down to MCU and SoC budgets.

Knowledge distillation

A large teacher Mt transfers domain reasoning to a compact student Ms (Hinton et al., 2015).

Ltotal = (1 − α)·Ltask + α·T²·KL(Pt ‖ Ps)

INT4 / INT8 quantization

Survey figures the paper cites: over 50% less memory and over 2× faster inference, with minimal accuracy loss.

Structured and magnitude pruning

Weights, heads or channels below a sensitivity threshold τ are removed, giving sparse, low-latency graphs.

wp = 0 if |w| < τ, else w

Memory-efficient attention

Grouped-Query Attention (Ainslie et al., 2023) or Multi-Head Latent Attention shares key-value caches across query groups; RoPE and RMSNorm bound SRAM on edge NPUs.

Cascaded control loops

Nano models (Qwen2-0.5B, MobiLlama-0.5B, SmolLM-135M/360M, OpenELM-270M) handle sensory filtering, immediate safety heuristics and routine tokens on device. An out-of-distribution exception or a system-wide diagnostic cascades up to an edge server or cloud-augmented SLM for planning.

Hardware-in-the-loop development

Virtual hardware such as Wokwi lets an agent flash firmware to a simulated MCU, watch GPIO and PWM, and self-correct before deployment. EmbedCopilot-Bench evaluates vision-language models on schematics, layouts and register configurations (Yuan et al., 2026).

§3.2 · Data ingestion and dual-level objectives

Two objective functions, with arbitration to test

Hardware I/O as a sliding context window

Raw readings are normalized into state tokens such as [TEMP-CRIT-104C] or [FLOW-RATE-DEGRADED], and the recent register history becomes the model's context:

[System-Tick: 1042]→[IO-In: Vin=4.2V, Iout=1.8A]→[Local-Obj: Maximize-Efficiency]→[SoS-Obj: Node-Power-Cap=10W]
L(x)

Local objective

Expressed as priorities in the Tier 2 system prompt: stability, minimal wear and immediate operational goals. A prompt does not guarantee local safety; record the proposed decision and the independently protected committed action separately.

G(x)

Global SoS objective

Built at Tier 3 from grid pricing, load forecasts and weather, then broadcast as Policy Envelopes over CAN, EtherCAT, Modbus-TCP or ROS2, e.g. [MAX-BATTERY-RESERVE-DISCHARGE] [LOAD-SHED-PRIORITY-HIGH].

The paper's arbitration example

A battery node receives a global request while reading its own health.

Global Policy Envelope[AGGRESSIVE-DISCHARGE]
Local physical health token[CELL-TEMP-CRIT]
↓
Battery node SLMThe intended response is to prioritize local safety over the global request. Test whether the model actually does so.
↓

Balancing across nodes: under the global goal of maximum system efficiency and revenue, a battery node (local target: minimize degradation) dictates its max discharge, while an appliance node (local target: user comfort) defers its HVAC cycle.

§3.3 · Execution pipeline and deterministic guardrails

Every proposal passes the interlock

The SLM never writes pins. It proposes a register map; a compiled C/C++ kernel or bounded SMT verifier checks it against physical limits (Sha, 2001; Mohan et al., 2013; Nesti et al., 2026).

Try a proposal

Example field and bound from the paper's node code listing (§5.1): chargeCurrentLimitA, 120.0 A. The corrected paper clamps valid out-of-range numbers and drops malformed output. §4.1 · Hardware Translation Matrix

From volts to tokens, with hysteresis

The HTM runs as deterministic firmware on the Tier 2 processor. Its Dynamic Boundary Processor splits each register into Magnitude, Delta and Frequency/noise tokens, each with a 16-bit hex ID.

§4.2 · ETL pipeline and training data

Control-state engineering textures, not web text

Pillar 1 · Industrial telemetry interleaving

SCADA archives, historians (TimescaleDB) and inverter logs; the HTM turns floating-point time series into chronological state-token transitions.

Pillar 2 · Hardware domain context

Component datasheets, battery thermal manuals, firmware register maps and IEEE 1547 compliance protocols, parsed into structured markdown rule sets.

Pillar 3 · Operator-in-the-loop interventions

Maintenance logs, override tickets and field records, such as retarding DC bus engagement by 15 minutes when Inverter 4 shows a high-side leakage spike under morning dew.

Four-block causal reasoning format

Instruction tuning makes the model justify its physics before emitting registers. The paper's worked sample:

§4.3 · Metaheuristics and hyper-heuristic supervision

The SLM steers the optimizers

An SLM cannot reliably optimize a nonlinear, multi-variable equation through token generation alone. PSO runs on each Tier 2 node (e.g. finding the global maximum power point on a partially shaded string); GA runs at Tier 3 (e.g. battery discharge sequencing across 50 nodes over 24 hours). The SLM supervises them (van Stein & Bäck, 2025; Narimani & Emami, 2026).

1 · Solution-space bounding

On fragmented cloud shading, the PSO tilt search narrows to 12° to 18° instead of the full 90° horizon.

2 · Fitness function adaptation

[MODE: BAT-CONSERVE]

On this SoS token, the SLM rewrites the active fitness function's penalty weights so searches aggressively penalize battery temperature spikes.

3 · Algorithmic switching

PSO→ no convergence within the timeout window →Simulated annealing

The SLM halts the PSO thread and starts an alternate recovery algorithm, such as a simulated annealing cooling loop, to reset the system smoothly.

§5 · Distributed solar farm implementation

A swarm of node SLMs under one orchestrator

Each node runs a quantized 500M to 1.5B SLM on an ARM Cortex-M7, STM32MP1 or NPU module, talking to the Global SoS Orchestrator over Modbus-TCP / CANopen.

The node control loop (§5.1 listing)

1 readRegisters() raw physical telemetry 2 tokenize [NODEID: BAT04] [SOC: 89.2%] [TEMP: 42.1C] [TREND: STEEP-RISE] 3 fuse [GLOBALSOS: DEMANDSURGE] [PRICE-SIGNAL: HIGH] 4 generate quantized on-device 1B SLM "Maintain cell safety above all else." # Prompt priority is a testable instruction. 5 guardrail if chargeCurrentLimitA > 120.0: chargeCurrentLimitA = 120.0 # One-field clamp; not a stability proof. 6 writeRegisters() DAC, PWM, Modbus

Five micro-scale paradigms for energy capture (§5.2)

Layer 1

Cell degradation and bypass hypothesis

Test degradation detection using identifiable voltage, current, impedance and bypass-state observations. Series-path current alone does not locate a weak panel; masked-panel tests are proxies for defects.

Layer 1 + sky imaging

Cognitive albedo tracking

When diffuse light off clouds, panels, ground or water beats the obscured direct beam, trackers tilt slightly away from the sun.

Layer 7 + Layer 1

Thermal detuning hypothesis

Test whether detuning before a clear-sky window changes panel temperature and net energy. Reduced electrical extraction can leave more absorbed energy as heat. Cooling is not assumed; measure panel and converter temperatures separately.

SoS cross-layer

Swarm wake deflection

At low sun angles, front rows flatten their tilt to clear shadows for rear rows and lift net farm yield (Cooper et al., 2025).

Layers 1 – 2

EMI noise harvesting

Inverters shift switching frequencies so IGBT noise cancels or aligns with passive capacitor harvesting loops feeding the DC bus (Zhang et al., 2021).

§6.3 · Communication protocol-specific SLM

A semantic gateway between OT fieldbuses and IT

Byte stream sniffer → protocol tokenizer → semantic cross-router. Select a byte to see the token it maps to in the paper's example frame.

Byte-to-token compilation

[MODBUS-READ][SLAVE-01][START-REG-32][LEN-2][CRC-VALID]

A deterministic parser validates transport framing and discovers the SunSpec model chain before interpreting fields. RTU uses a trailing CRC; Modbus TCP uses an MBAP header and no RTU CRC. On [MODBUS-ERROR-04], the SLM checks Layer 1 noise to tell line noise from an overloaded inverter MCU and throttles polling instead of crashing the bus.
